# Flapbird

Uma variação simples do jogo Flappy Bird. Desenvolvido usando HTML, CSS, JavaScript e o elemento `<canvas>`.

## Descrição
- **Controles**: Pressione ESPAÇO para fazer o Sonic "flapar" (pular).
- **Objetivo**: Evite os canos e marque pontos.
- **Tecnologias**: HTML5 Canvas, CSS para estilos, JS para lógica.
